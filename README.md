# Personal Website by Jeffrey Yu



## About

This is the personal website for Jeffrey Yu, which has been constructed with HTML, CSS, and JavaScript. 
The website has been created in order to present a professional side to employers and
potential visitors. The website contains the following webpages:

- `index.html` - Landing Page, home page that introduces myself
- `portfolio.html` - Portfolio Page, a page where you will find projects I have 
    done in the past and future projects I would like to complete.
- `qualifications.html` - a page with my resume and areas of interest displayed
- `activities.html` - a page that shows activities that I'm interested in
- `sandbox.html` - an AI generated sandbox page that shows a MLB scoreboard

The website supports two different styles and layouts on all pages except for the sandbox page.
`styles.css` provides the original light gray background with orange hanging navigation bar, 
and `styles2.css` has a dark blue menu with a lighter transparent background.

`script.js` allows users to toggle in between the two styles while accessing the pages, 
which can be done by simply clicking the "Toggle Style" button. 

The sandbox page is not available for theme toggling since it has its own css styles.
